# ScreenClip

macOS 用のスクリーンショット & 画像編集アプリ。キャプチャしてそのまま注釈・加工・書き出しまでを 1 ウィンドウで完結させます。

メニューバーに常駐し、グローバルショートカットでいつでもキャプチャできます。

## 主な機能

### キャプチャ
- 範囲選択キャプチャ / 画面全体キャプチャ（ショートカットは環境設定で変更可能）
- キャプチャと同時にクリップボードへコピー
- 自動保存（保存先フォルダは環境設定で指定）

### 注釈ツール
| ツール | キー | ツール | キー |
|---|---|---|---|
| 選択 | V | 四角 | R |
| 画面移動 | H | 楕円 | E |
| 切り抜き | C | テキスト | T |
| ペン | P | モザイク | O |
| マーカー | M | ぼかし | B |
| 直線 | L | 矢印 | A |

- 描いた図形は選択ツールで移動・リサイズ・削除でき、色と太さは後からでも変更できます
- テキストは色と文字サイズを指定して追加・編集できます
- 元に戻す / やり直す（⌘Z / ⇧⌘Z）に対応

### 画像調整
- 明るさ、コントラスト、彩度、色相、シャープ、ぼかし、白黒
- 回転（90度単位）、左右／上下反転、サイズ変更、切り抜き

### 書き出し
- PNG / JPEG / TIFF / BMP / GIF を保存ダイアログで選択（⌘S）
- 保存先フォルダへワンクリック保存（⇧⌘S）
- 編集後の画像をクリップボードへコピー（⌘C）

## ショートカット

| 操作 | 初期値 |
|---|---|
| 範囲を選択してキャプチャ | ⌘⇧4 |
| 画面全体をキャプチャ | ⌘⇧F |
| 名前を付けて保存 | ⌘S |
| 保存先にすぐ保存 | ⇧⌘S |
| 画像をコピー | ⌘C |
| 貼り付け | ⌘V |
| 全体表示 / 実際のサイズ | ⌘0 / ⌘1 |

キャプチャ用の 2 つは **環境設定（⌘,）> ショートカットキー** から変更できます。

> **Note**
> 初期値の ⌘⇧4 は macOS 標準のスクリーンショットと同じ組み合わせです。両方が同時に反応する場合は、
> システム設定 > キーボード > キーボードショートカット > スクリーンショット で標準側を無効にするか、
> ScreenClip 側のショートカットを別のキーに変更してください。

## 動作環境

- macOS 13 (Ventura) 以降
- Apple Silicon / Intel の両方に対応（ユニバーサルバイナリ）

## ビルド

```sh
git clone https://github.com/<user>/ScreenClip.git
cd ScreenClip
./build_app.sh            # ScreenClip.app を生成
./build_app.sh --install  # /Applications にインストールまで行う
```

開発中は Swift Package Manager でそのまま実行できます。

```sh
swift build
.build/debug/ScreenClip
```

## 初回起動時の設定

1. **画面収録の許可**: 初回キャプチャ時にシステムから許可を求められます。システム設定 > プライバシーとセキュリティ > 画面収録 で ScreenClip を有効にしてください。
2. **Gatekeeper**: 配布バイナリはアドホック署名のみ（Apple Developer ID による公証なし）のため、他の Mac では初回起動がブロックされます。アプリを右クリックして「開く」を選ぶか、システム設定 > プライバシーとセキュリティ から許可してください。
